# 仿真评估工具

`mv-tool-simulation-evaluation` 在正式视觉结果生成后消费同帧相机模型、平台运动学和 Talos
仿真真值，负责真值投影、检测一对一匹配、PnP/角点精度、预测误差及累计分组统计。正式
检测、PnP、预测和控制模块不包含仿真类型，也不读取评估结果。

运行时先把正式预测提交给 100 Hz 控制线程，再同步执行评估。缺少完整空间数据或真值时
跳过当前帧；评估异常只记录警告，不改变正式流水线退出状态。匹配门限由
`src/config/tool/simulation_evaluation.yaml` 管理，误差仍按 `estimate - truth` 定义，PnP
统计每 100 个源帧序号生成一次原子快照。

评估输入显式接收检测、最终角点、角点诊断、正式 PnP、PnP 诊断和正式预测。它可以读取诊断
来计算精修健康和求解误差，但评估结果不会回流到任何正式输出或控制门控。

Foxglove 兼容层继续把正式输出、诊断输出与可选评估结果组合成原有话题和 Schema。MCAP 可
用于只读分析当前运行效果；修改后算法在同一 MCAP 上确定性重放需要后续增加专用回放源。
