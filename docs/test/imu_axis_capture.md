# IMU 安装轴向单轴实验

临时采集工具复用 ControllerLink 的握手、CRC、会话和时钟同步，逐帧保存 IMU 四元数与
角速度；只发送握手和同步消息，不发送云台运动或开火指令。不需要相机，也不启动 MCAP。

## 启动

先停止占用同一串口的视觉主程序及串口调试软件。在项目根目录运行：

```bash
bash scripts/capture_imu_axes.sh /dev/ttyUSB0
```

设备参数以实机为准，可以使用 `/dev/serial/by-id/...`。脚本用 C++20 编译器独立构建到
`build-imu-axis/`，不需要 OpenVINO。完整 CMake 构建中也有 `mv-imu-axis-capture` 目标。
第二个可选参数指定一个尚不存在的输出目录；默认创建 `artifacts/imu_axis/<时间戳>/`。
单次最多 600 秒，输入 `q` 回车或 Ctrl+C 结束并保存。未收到可接纳帧时返回码为 2。

等待 `ready=yes`。`ready=no` 时不能开始实验阶段；检查设备、串口占用及固件姿态链路。
状态里的角速度单位为 rad/s，未就绪时显示值可能是上一次有效帧，不能用于判断当前运动。

## 操作顺序

所有命令均需回车。按下命令后等约 1 秒再开始动作，动作结束后停约 1 秒，再切换阶段。
固定底盘，先将枪口置于水平。这里的左右是从上向下看，抬头指枪口升高。

1. 输入 `s`，保持静止约 5 秒，记录偏置与噪声。
2. 输入 `l`，保持 pitch 水平，缓慢单向左转；停止后输入 `p`，复位到起始位置。
3. 输入 `r`，保持 pitch 水平，缓慢单向右转；停止后输入 `p`，复位。
4. 输入 `u`，固定 yaw，从水平缓慢抬头；停止后输入 `p`，复位。
5. 输入 `d`，固定 yaw，从水平缓慢低头；停止后输入 `p`，复位。
6. 每种动作重复 2–3 次，各次重新输入对应标签；最后输入 `s` 静止约 5 秒，再输入 `q`。

每次运动建议持续数秒，在机械允许范围内取得清晰角速度即可，不必达到某个固定角度。
运动阶段内只做指定方向；反向复位必须放在 `p` 阶段。断线/重建会话会自动切回 `pause`。
标签记录的是主机接收时刻，不是精确的 MCU 动作边界，分析时需要剔除切换边缘与静止样本。

## 数据及后续分析

输出 `samples.csv` 和 `README.txt`，将目录路径告诉 Codex 即可继续分析：

- 保存 MCU 微秒时间、主机接收时间、传输序号、INS 样本序号、会话代次和实验段号。
- `qw,qx,qy,qz` 是 IMU 解算机体系到惯性系的原始四元数；`wx,wy,wz` 是同帧机体系角速度。
- `flags`、`synchronized`、`accepted`、时钟偏差、RTT 和 CRC 累计错误用于筛选质量。
  无效/重复/未同步样本仍记录，但 `accepted=0`；四元数不在采集时归一化，保留原值。
- 分析时先检查丢帧、时间连续性、阶段覆盖与静止噪声，再比较正反向轴的一致性。
  水平左转对应云台 +Z，抬头对应云台 -Y。两轴足够确定右手系旋转，但明显混轴时
  需要区分安装倾斜与操作中的混合运动，不能直接认定为安装误差。
- 分析给出 `gimbal_r_imu` 候选与证据，不自动覆盖实机外参，也不根据单次运动宣称精度。

实机接收、手动运动标签和安装矩阵结果均需用户实机验证。
